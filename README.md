🌐 Advanced Android WebView (Jetpack Compose)
A robust, modern Android WebView implementation built with Jetpack Compose. This project serves as a high-performance wrapper for web applications, providing native-like features and seamless integration between web and mobile.

✨ Key Features
⚡ Modern Architecture: Built entirely using Jetpack Compose and AndroidView interop.

🎥 Full-Screen Video: Supports HTML5 full-screen mode with native system bar management.

📂 File Management:

Native Download Manager integration with cookie support.

File Upload support via a native system file chooser.

🔐 Permission Handling: Integrated runtime requests for Camera, Microphone, and Geolocation.

🌍 Smart Navigation:

Handles tel:, mailto:, sms:, and geo: links.

Support for intent:// schemes (e.g., opening YouTube or WhatsApp directly).

Chrome Custom Tabs fallback for external links.

🔍 Built-in Search Bar: Intelligent address bar that recognizes URLs vs. Google search queries.

🔙 Advanced Back Handling: Gracefully handles web history, full-screen video exit, and app closing.
